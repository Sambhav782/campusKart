# CampusKart

CampusKart is a campus-first marketplace prototype for students to buy, sell, and discover useful items within their college community.

## Frontend prototype

Built with React + Vite. The prototype includes marketplace search, category filtering, responsive product cards, favorites, product detail modal, demo sell flow, demo sign-in, and a campus trust/how-it-works section.

## Run locally

1. npm install
2. npm run dev

The current listings use mock data and remote demo images. Backend/API integration comes next.
